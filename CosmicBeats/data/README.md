## Details on configuration files
- Topology TLE: The latest TLEs can be found in [Celestrak](https://celestrak.org/)
- Coloring of satellite: Users are encouraged to change the color mapping. The two example mappings we released are the configuration we used in our paper. For customization, collect the latest orbital shell information from [starlink.sx](). The shell information can be used to infer the neighbor relationships between satellites and can be further used to assign buckets.
